# Frontend fixtures

Synthetic data only, generated by `node scripts/make-fixtures.mjs` from `demo/states/`
(`northstar/*` repositories with invented handles).

| Fixture | Shows |
|---|---|
| `hackathon` | Active work, a declared mission rail, and a synthetic event schedule. No knowledge file is published, so that optional input appears as unavailable. |
| `quiet` | Nothing in flight; only the required inputs are present. |
| `broken` | An unsupported snapshot version and an unreadable scene file. |

In dev, `npm run dev` serves this folder. Pick a fixture with `?data=<fixture>/data/`; the
default is `hackathon`.

Real consumer data (for example the BaselHack Open Presence Pages output) is only used locally
for verification. It is never committed here; development-practice principle 6.
