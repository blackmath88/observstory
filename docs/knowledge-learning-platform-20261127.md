# Knowledge and learning integration — producer contract proposal
2026-11-27 | Design note

Observstory already provides typed repository observations, derived/heuristic/declared signals, selected project knowledge and revision-scoped memory contracts. Keep the producer-owned snapshot and source manifests as the integration boundary.

A generic downstream knowledge platform may capture explicitly selected versioned snapshots and derive historical views, preserving observed/derived/heuristic/declared distinctions, evidence references, coverage and source permissions. Do not assign downstream models authority to change observations or accept repository proposals. Use existing proposal/review files for approved writeback. Validate snapshot version compatibility, stale/missing source behavior, denied access and replay on synthetic data. No new hosted publication, dependency or deployment authorized. This is a generic public design note, not a claim of live integration.
