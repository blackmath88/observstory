# Jobs to be done: collaboration state

## Primary
> **When** my team agrees on something in a quick check-in (a freeze, a gate, who takes what),
> **I want** those few agreements written down once and compared with what the repository then does,
> **so that** we notice a crossed freeze or an unstarted commitment while there's still time to act.

## Secondary
1. **When** I join a project midway, **I want** to see NOW, the next gate and which commitments have work behind them, **so that** I understand the plan against reality in a minute.
2. **When** a check-in ends, **I want** the notes turned into *proposed* decisions and commitments that I can fix and confirm, **so that** capture takes two minutes, not twenty.
3. **When** a coding agent starts work, **I want** it to see the current gates and any freeze that applies to the paths it will touch, **so that** it doesn't reopen a frozen area unknowingly.
4. **When** we review the project afterwards, **I want** a timeline of check-ins, decisions and gates, **so that** we can reconstruct how we got here.

## Declined
> When I lead a team, I want to see who keeps their commitments.

That's per-person scoring (K1). Declined.
